## 課後測驗與結業證書（`quiz.html`）

- 10 題單選，題序與選項順序每次隨機；每題 10 分，**80 分（含）以上通過**（`quiz.html` 內 `PASS_SCORE` 可調整）。
- 作答前須填寫：公司名稱、單位、姓名、職稱、e-mail（必填，e-mail 檢查格式）。
- **通過**：畫面顯示證書預覽，可下載「結業證書 PDF」（第 1 頁為證書，含證書編號；第 2 頁起為全部題目、本人作答、正確答案及解析），或下載證書 PNG。
- **未通過**：只顯示分數，不公布答案，並提供「重新觀看課程」「重新測驗」。
- 純前端運作，所填資料不會上傳；如需集中保存受訓名冊，可再串接 Google 表單或內部系統。
- 題庫在 `quiz.html` 的 `QUESTIONS` 陣列，可自行增修。PDF 使用內附 jsPDF（MIT 授權，`assets/vendor/`）。

## 修改與重製

```bash
pip install edge-tts numpy certifi      # 配音
./fetch_fonts.sh                        # （已附字型；需要時重新下載 Huninn、Noto Sans TC，OFL 授權）
python3 build_audio.py                  # 產生配音、時間軸與音軌 → build/
node render.js stills 10 60 120         # （選用）輸出指定秒數截圖檢查版面
node render.js video --fps 24 --workers 4   # 逐格錄製並合成 MP4（需 Playwright + ffmpeg）
```

- 台詞與畫面內容都在 `scenes.js`，改完重跑上面三個指令即可（配音有快取，只會重新合成改過的句子）。
- `player.html` 是互動播放器（動畫 + 配音，可拖曳進度）；儲存庫根目錄的 `index.html` 為入口頁，以任何靜態伺服器（例如 `npx http-server` 或 GitHub Pages）開啟即可。
- 若要換成其他公司的窗口名稱（例如「資訊室」「儀電課」），只需修改 `scenes.js` 對應文字。

## 法規依據

- 資通安全管理法（114 年 9 月 24 日修正公布）第 24 條（特定非公務機關通報應變）、第 29 條（未通報罰則）
- 資通安全事件通報應變及演練辦法（115 年 1 月 5 日修正發布）：事件分級、一小時通報、主管機關審核 8／2 小時、72／36 小時損害控制或復原、調查處理及改善報告、演練
- CNS 27001:2023 / ISO/IEC 27001:2022 附錄 A 5.24–5.28、6.8

> 注意：115 年修正之辦法已刪除第三、四級事件中「敏感資訊」之判定要件，引用舊版分級表之程序書宜一併修訂。
