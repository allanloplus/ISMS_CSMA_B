# 資安事件通報與應變｜教育訓練動畫（公務機關 B 級版）

適用對象：資通安全責任等級 **B 級之公務機關**全體同仁（僅 IT 環境）。
講者：講師 **Allan**（右，台灣男聲）主講；助教 **阿拉蕾**（左，可愛女聲）串場。
片長約 15.1 分鐘，1920×1080，內容不含任何機關名稱，可直接用於同性質單位。

## 成品

- `資安事件通報與應變_教育訓練動畫_公務機關B級.mp4`：成品影片
- `player.html`：互動播放器；`quiz.html`：課後測驗與結業證書（欄位為「機關名稱」）
- 入口頁：儲存庫根目錄 `index_g_b.html`

## 與特定非公務機關版（`../incident-training-video/`）的差異

| 項目 | 公務機關版 |
|------|-----------|
| 通報對象 | 知悉後 1 小時內至主管機關指定之系統平臺，通報上級或監督機關及主管機關（資通安全管理法第 17 條） |
| 等級審核 | 受通報機關：一、二級 8 小時內；三、四級 2 小時內 |
| 法律責任 | 所屬人員依情節輕重予以懲戒或懲處（第 28 條），非罰鍰 |
| 通報窗口 | 上班時間：資訊單位資安窗口；非上班時間：資訊單位 24 小時電話／值日人員 |
| 角色 | 資安窗口、資安主管、資安專職人員、資通安全長 |
| 案例 | 案例一：檔案伺服器勒索軟體（第二級）；案例二：線上申辦系統 SQL 注入、民眾個資外洩（第三級，含依個資法通知當事人） |
| 演練 | 主管機關規劃之社交工程演練（每半年）、通報及應變演練（每年），機關自辦演練每年至少一次 |
| OT | 不含 |
